## **Project Overview**

A e-commerce platform designed to provide a seamless experience for merchants and customers. The platform includes features for product management, category management, user management, and order processing. It supports both admin and merchant roles, with separate dashboards and functionalities.

---

## **How to Run the Project**

### **Backend**

1. Navigate to the backend directory:
    
    cd backend
    
2. Install dependencies:
    
    npm install
    
3. Start the server:
    
    npm start
    

### **Frontend**

1. Navigate to the frontend directory:
    
    cd frontendmer
    
2. Install dependencies:
    
    npm install
    
3. Start the development server:
    
    npm run dev

### 🔧 **Frameworks & Libraries**

- **React.js + Redux Toolkit**: Gives you powerful state management with a predictable structure (slices, thunks).
- **React Router**: Clean navigation and route handling.
- **React Hot Toast**: Makes user feedback slick and easy.
- **React Bootstrap + MDB UI Kit**: Combines custom styling with ready-to-use components and responsive layouts.
- **React Slick + React Paginate**: Perfect for rich UIs like carousels and paginated views.
- **Axios**: Streamlined API communication with easy error handling and interceptors.
- **React Redux Persist**: Keeps Redux state alive across page refreshes—great for auth or cart features.

### 🎨 **Styling**

- **CSS + Bootstrap + MDB UI Kit**: Gives you flexibility and rapid prototyping. You're not locked into one visual style.
- **Font Awesome & React Icons**: Makes UI more intuitive and appealing.

### ⚙️ **Build Tools & Quality**

- **Vite**: Super fast dev/build experience. Great choice for modern projects.
- **ESLint**: Keeps your codebase clean, readable, and consistent.

### 🔗 **API & Backend Integration**

- **RESTful APIs via Axios**: Decouples frontend from backend, making it easier to migrate or scale backend services.
- **AWS S3**: Great for delivering static assets reliably and quickly.

### **Backend**

- **Node.js**: For server-side scripting.
- **Express.js**: For building RESTful APIs.
- **MongoDB**: For database storage.
- **Mongoose**: For MongoDB object modeling.
- **JSON Web Tokens (JWT)**: For authentication.
- **dotenv**: For environment variable management.
